# 1puni/.github

The [1puni org profile](https://github.com/1puni). The page itself is
[`profile/README.md`](profile/README.md).

Everything in `profile/assets/` is generated by `tools/build.py` from the approved
logo crops in `brand/` (the same crops 1puni.com ships). Edit the script, then:

```sh
python3 tools/build.py
```

Palette, type and copy follow 1puni.com. Poster statuses are copied from the
site's own honest labels; if a project's status changes there, change it here.
`brand/avatar-yellow.png` is the org avatar (GitHub has no API for it; upload
it at Settings → Profile).
